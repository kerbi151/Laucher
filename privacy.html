Prywatnosc

Laucher Serwera jest aplikacja desktopowa dla Minecraft Java / NeoForge. Laucher nie prosi o haslo Microsoft i nie zapisuje hasla uzytkownika.

Logowanie premium odbywa sie przez Microsoft OAuth. Token odswiezania, nick gracza, UUID oraz ustawienia lauchera sa zapisywane lokalnie na komputerze uzytkownika.

Laucher pobiera manifest modpacka i pliki paczki z publicznego adresu skonfigurowanego w aplikacji. Dane nie sa sprzedawane ani wysylane do prywatnego serwera analitycznego.

Kontakt i kod projektu moga byc dostepne w repozytorium GitHub wlasciciela lauchera.
